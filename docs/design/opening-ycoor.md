# Ouvrir le secteur Ycoor

Ouvrez la P0.6.7 dans votre navigateur pour voir la carte 3D et les bâtiments DXF. Activez **Relevé Street View** pour consulter les captures ou cliquez sur **Vérifier les objets MO de Ycoor** pour consulter les données cadastrales. [Ouvrir la P0.6.7](https://djbebs.github.io/mini-crans-montana/crans-montana-p067/)

Depuis l’accueil de Mini Crans-Montana, cliquez sur **Ouvrir la dernière version**. [Aller à l’accueil](https://djbebs.github.io/mini-crans-montana/)

Si vous double-cliquez sur `preview-ycoor-design/index.html` ou sur `crans-montana-p067/index.html`, le navigateur vous redirige automatiquement vers la P0.6.7 en ligne. Une connexion Internet est nécessaire.

## Voir vos modifications locales

Depuis le dossier principal du projet, lancez le serveur de développement avec Python.

```sh
python -m http.server 8000
```

Gardez le serveur ouvert pendant que vous consultez l’aperçu. Vous pouvez l’arrêter avec Ctrl+C. [Ouvrir l’aperçu local](http://localhost:8000/preview-ycoor-design/)
